# Machine Learning

A collection of learning resources, practice notebooks, and hands-on implementations covering the fundamental tools and concepts used in **Data Science and Machine Learning**.

This repository documents my learning journey through Python-based data analysis, visualization, and machine learning fundamentals.

## Overview

The purpose of this repository is to build a strong foundation in the Python ecosystem used for Machine Learning and Data Science.

It currently includes practice with:

* NumPy
* Pandas
* Data Visualization
* Jupyter Notebooks
* CSV Data Analysis
* Exploratory Data Analysis (EDA)

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/student-sayan/machine_learning.git
```

Navigate to the repository:

```bash
cd machine_learning
```

### Install Required Libraries

```bash
pip install numpy pandas matplotlib jupyter
```

### Start Jupyter Notebook

```bash
jupyter notebook
```

Open the required `.ipynb` file and run the cells to explore the examples.
